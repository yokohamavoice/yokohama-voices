# ヨコハマの声

横浜の政策について意見を集め、考え方の違う人たちにも共通して支持される意見を探すプロジェクトです。Polisの仕組みと公開コードを参考にしています。

## どんなことができる？

ログインせずに参加できます。表示された意見に「賛成」「反対」「パス」「無関係」で答え、回答を終えたら自分の意見も投稿できます。最初は8分野・40件の意見を用意しています。

集まった回答から、似た考え方のグループや、異なるグループに共通して支持される意見を見つけます。集計は参加した人たちの回答に基づくもので、横浜市民全体の世論調査ではありません。

**現在はコードを公開し、Cloudflareでサイトを動かす準備をしています。データの自動保存処理も、接続が完了するまで停止しています。**

## サイトとデータはどこに置く？

Cloudflareは、サイトを動かしたり、データを保管したりするサービスです。GitHubにはサイトのコードと、運営者が確認を終えた公開用データを置きます。

| 置くもの | 保存先とその役割 | 誰が見られる？ |
| --- | --- | --- |
| サイトを動かすプログラム | GitHubのこのリポジトリで公開し、Cloudflareの **Workers** で動かします | コードとサイトの画面は公開対象です |
| 投稿・回答・意見の表示履歴など、元の記録 | Cloudflareの **D1**。記録を整理して保存するデータベースです | 元の記録は非公開。承認した意見や集計結果だけをサイトで表示します |
| 分析結果の保存版・公開前に確認するデータ一式 | Cloudflareの **R2**。ファイルを保管する場所です | 保管場所は非公開。サイトで見せる結果や、公開を承認したデータだけを取り出します |
| 確認・承認を終えた分析用データ | [GitHubの公開データリポジトリ](https://github.com/yokohamavoice/yokohama-voices-data) | 誰でも取得して分析できます |
| 投稿の確認一覧・運営者の判断記録 | GitHubの非公開リポジトリ | 運営者だけが確認します |

D1とR2は、どちらもCloudflareの保存サービスの名前です。日々の投稿・回答の記録にはD1を、まとまったファイルの保管にはR2を使います。

## 運営者は何を承認する？

承認する場面は、次の2つです。

### 1. 新しく書かれた意見をサイトに載せるとき

参加者が書いた意見は、**1件ずつ内容を確認してから掲載**します。最初から用意した40件の意見は掲載済みの扱いです。

**「賛成」「反対」「パス」「無関係」の回答には、1票ごとの承認は不要です。** 回答するとそのまま記録されます。

掲載後の意見も、前回の確認から「無関係」が3件増えた場合や、新しい通報が届いた場合は確認一覧に入ります。件数だけで自動的に消えることはなく、運営者が掲載を続けるか判断します。

### 2. 分析用データをGitHubで公開するとき

公開するデータをひとまとめにして確認し、そのまとまりに版を付けて承認します。これは、回答を1票ずつ承認する作業ではありません。

**元の記録を保存 → 公開用データを作る → 内容を確認・承認 → GitHubに保存**、という順番です。未確認の投稿や元の記録が、そのまま自動でGitHubに公開されることはありません。

## 研究利用について

投稿・回答や表示履歴は、研究や分析結果の公表に使うことがあります。公開用データには、掲載を承認した意見と回答、表示順、抽選確率などを含めます。投稿者と回答を結びつける情報、詳しい時刻、認証情報などは含めません。自由記述や回答の組合せから個人が推測される可能性は残るため、公開前に内容を確認します。

参加時の詳しい案内は、サイト内の「研究利用とデータ公開」に掲載します。
